# Performance Measurements

**상태:** 결과 없음. 수치 추정이나 추측을 측정값으로 기록하지 않는다.

## 측정 대상

입력→VN Response End-to-End 지연, LLM/Embedding Latency/호출 수, Context Assembly/Validation/Commit Latency, Token/추정 Cost, Error/Retry, Emotion/Expression Host ID Lookup Cost, 동일 캔버스 PNG Layer 합성 메모리·시간.
