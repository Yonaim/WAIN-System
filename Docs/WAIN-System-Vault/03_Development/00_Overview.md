# Development 문서의 역할

이 폴더는 **진행 중인 구현 작업과 현재 설계 선택**을 기록한다. 현행 시스템 구조와 계약은 [[02_Architecture/00_Overview|Architecture]], 실행된 테스트와 측정 결과는 [[04_Experiments/00_Overview|Experiments]]에 둔다.

| 문서 | 들어갈 내용 |
|---|---|
| [[01_Current-Work|Current Work]] | 현재 작업, 다음 단계, 완료 조건과 미완료 범위 |
| [[02_Current-Choices|Current Choices]] | 현재 선택, 근거, 재검토 조건 |

현재 작업 경로에 프로젝트 코드나 요구사항이 없으므로 구체적인 구현 작업은 기록하지 않았다. 프로젝트 자료 확인 후 갱신한다.
