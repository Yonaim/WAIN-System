# WAIN System 문서 Vault

이 Vault는 WAIN System의 연구 기준, 아키텍처 계약, 구현 계획, 검증 근거를 관리한다. Obsidian에서 [[00_Home|00_Home]]을 시작점으로 연다.

## 근거 자료와 우선순위

- 현재 설계 기준: 저장소 루트의 [설계 인계 문서](../../../../설계.md)
- 중간발표 시점의 범위와 발표 원고: [[06_Assets/README|06_Assets 색인]]
- 구현 상태: 실제 Plugin 코드와 설정을 근거로 판단한다. 설계만으로 구현 완료를 판정하지 않는다.

설계 문서와 발표 자료가 다르면 최신 설계 인계 문서에서 확정·미확정 상태를 확인하고, 발표 자료는 발표 당시 설명의 근거로 사용한다. 구현 사실은 소스 코드와 실행 결과로 확인한다.
