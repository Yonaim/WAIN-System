# 평가 개요

> 상태: 평가 계획안. 제공된 자료에는 실험 결과가 포함되어 있지 않다.

## 평가 목표

비주얼 노벨 상호작용에서 WAIN 아키텍처가 캐릭터의 지속 경험, 월드 인지, 일관된 서사 진행을 개선하는지 평가한다.

## 시스템 단계

| 단계 | 시스템 구성 |
|---|---|
| A | LLM 단독 기준선 |
| B | A + Character Agent |
| C | B + World State Manager |
| D | C + Narrative Manager |

가능한 한 같은 시나리오와 플레이어 입력을 각 단계에 적용한다. 이 누적 비교는 시스템을 단계별로 확장했을 때의 동작을 보여준다. 이후 단계에는 이전 단계의 기능이 포함되므로 각 구성 요소의 인과 기여를 단독으로 분리하지는 못한다.

## 품질 평가 지표

평가자는 다음 항목을 5점 척도로 평가하도록 제안되어 있다.

- 일관성
- 맥락 적절성
- 자연스러움

실제 평가 전에 점수별 기준, 평가자 지침, 표본 수, 집계 방법을 정해야 한다.

## 시스템 동작 지표

제안된 측정 항목은 다음과 같다.

- Memory 검색 관련성
- Commit된 캐릭터·월드 State가 상호작용을 정확히 반영하는지 여부
- Narrative Constraint 위반
- Beat 완료와 전이의 정확성

측정 전 분모와 실패 분류를 정의한다. 계획한 지표를 측정 결과처럼 보고하지 않는다.

## 결과 기록

시나리오와 Prompt 버전, Model·Provider, 초기 State, 설정, 실행 날짜, 원시 출력, 평가자 또는 평가 절차, 지표 계산법을 기록한다. 집계 점수와 함께 실패 및 제외 결과도 공개한다.
