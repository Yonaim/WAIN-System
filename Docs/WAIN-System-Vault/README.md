# WAIN System / Testbed 문서

이 문서 볼트는 `WAINTestbed` 저장소의 Unreal 통합 테스트베드와 WAIN System 플러그인의 현재 연결 상태를 기록한다. Obsidian에서 `00_Home.md`를 시작점으로 연다.

WAIN System 플러그인의 기존 문서 볼트는 `../../Plugins/WAINSystem/Docs/WAIN-Vault/`에 있다. 이 문서는 별도 Testbed 저장소 루트의 개발·통합 관점을 다루며, 플러그인 문서를 복제하거나 대체하지 않는다.

구성은 번호 체계, Architecture/Development/Experiments/Research 분리, Obsidian 상대 링크 및 재사용 문서 템플릿을 사용한다. WAIN 저장소의 요구사항과 코드만 프로젝트별 사실의 근거로 삼는다.
