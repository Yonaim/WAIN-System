# 용어집

> **한 줄 요약:** WAIN 프로젝트의 공식 용어와 책임 경계를 일관되게 사용한다.

| 용어 | 정의 | 근거·비고 |
|---|---|---|
| WAIN | World-Agent Interactive Narrative System for Visual Novels | 프로젝트 README |
| Character Agent | WAIN이 장기 상태를 바탕으로 동작시키는 캐릭터 에이전트 개념 | 상세 정의는 플러그인 Architecture에서 관리 |
| State Manager | 캐릭터·관계·감정·세계·서사 상태를 관리하는 공통 구성요소 예정 | README의 책임 설명 |
| Testbed | WAIN을 VN 형태로 통합·검증하는 Unreal 프로젝트 | 저장소 README |
| Adapter | Testbed 게임과 WAIN 공통 시스템 사이의 게임별 연결 구현 | README의 책임 경계 |
| 미구현/미확인 | 코드에서 기능을 확인하지 못한 상태 | 설계 의도와 구현을 구별하기 위해 사용 |
