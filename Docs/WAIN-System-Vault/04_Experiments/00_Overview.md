# 실험·검증 문서의 역할

이 폴더는 테스트와 검증의 **계획, 실행 조건, 실제 결과와 한계**를 보관한다. 미완료 구현 과제는 [[01_Current-Work|Current Work]], 현재 동작 계약은 [[02_Architecture/00_Overview|Architecture]]에 둔다.

| 문서 | 기록 내용 |
|---|---|
| [[01_Validation-and-Tests|Validation and Tests]] | 테스트 범위, 실행 명령, 환경과 결과 |
| [[02_Performance-Measurements|Performance Measurements]] | 성능 측정 조건, 반복 방법, 원자료와 해석 |

수행하지 않은 테스트나 측정값은 미실행으로 표시한다. 테스트 계획만으로 구현 검증이 끝난 것으로 표현하지 않는다.
