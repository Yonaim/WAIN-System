# Research 문서의 역할

WAIN은 LLM 기반 비주얼 노벨에서 캐릭터·관계·감정·세계·서사 상태를 LLM 바깥에서 유지해 장기 상호작용의 일관성을 지원하는 시스템으로 프로젝트 README에 소개돼 있다. 연구 목적과 범위의 원 출처는 제안서와 플러그인 저장소의 WAIN-Vault다.

이 폴더는 Testbed에서 검증할 연구 질문, 평가 기준과 근거를 요약한다. 플러그인 설계 정본과 주차별 프로젝트 계획을 복제하지 않는다.

- 프로젝트 배경·공식 명칭: [WAINTestbed README](../../../README.md) 및 `../../../Plugins/WAINSystem/README.md`
- 제안서: `../../../Plugins/WAINSystem/Docs/WAIN-Vault/07_Assets/26-2_졸업프로젝트_WAIN_제안서.pdf`
- 플러그인 문서: [WAIN-Vault 가이드](../../../Plugins/WAINSystem/Docs/WAIN-Vault/00_Start/0000_Vault-Guide.md)

현재 단일 에이전트 Testbed가 초기 검증 범위라는 점은 README에 명시돼 있다. 구체적인 가설, 비교 기준과 결과는 제안서 및 실제 실행 자료를 확인해 추가하며, 아직 성능·사용자 평가 결과는 기록하지 않는다.
