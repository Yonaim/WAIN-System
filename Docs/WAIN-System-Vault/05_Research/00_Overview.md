# 연구 개요

이 영역은 WAIN 설계의 문제 정의와 관련 연구를 정리한다. 기존 연구의 기법, WAIN 고유 설계의 종합, 아직 결정되지 않은 사항을 구분한다.

## 핵심 질문

LLM 기반 캐릭터 상호작용을 사용하면서 캐릭터 State, 월드 사실, 서사 진행을 여러 상호작용에 걸쳐 지속적이고 검토 가능하며 일관되게 관리하려면 어떤 구조가 필요한가?

## 설계 주제

- 지속형 Agent에는 현재 Prompt 바깥의 Memory와 State가 필요하다.
- 월드 Context는 관련성에 따라 선택하고, 공개 정책을 적용한 뒤 생성에 사용해야 한다.
- 서사 진행은 명시적인 Goal, Constraint, Condition으로 관리할 수 있다.
- LLM 생성 결과가 권위 있는 State를 변경하기 전에 검증해야 한다.
- 사용자 평가와 시스템 동작을 함께 측정해야 한다.
