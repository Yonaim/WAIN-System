# Unreal Engine C++ 코드 작성 기준

상태: **초안** · 제안서에서 확정된 구현 기반은 Unreal Engine C++ Plugin이다. 세부 명명·포맷 규칙은 실제 플러그인 코드와 저장소 설정을 확인한 뒤 확정한다.

## 현재 적용 기준

| 항목 | 기준 |
|---|---|
| 구현 형태 | 게임별 콘텐츠와 책임을 분리한 Unreal Engine C++ Plugin을 목표로 한다. |
| 엔진 연동 | Unreal Engine의 타입, 리플렉션, 모듈 및 객체 수명 규칙을 따른다. |
| 코드 스타일 | 저장소에 실제 설정 파일과 코드 기준이 마련되기 전까지 임의의 프로젝트 전용 규칙을 강제하지 않는다. |
| 시스템 경계 | Character Agent, World State Manager, Narrative Manager의 책임을 게임별 VN 콘텐츠와 구분한다. |

## 확정 전 보류 항목

제안서는 `namespace`, 타입 접두사, 파일명, 포맷터, 예외·오류 처리 방식과 같은 세부 C++ 규칙을 정하지 않는다. 따라서 다른 엔진 프로젝트에서 가져온 이름 규칙, `.clang-format` 기준, Vulkan/GLFW 전용 지침은 이 프로젝트의 규칙으로 사용하지 않는다.

플러그인 코드가 추가되면 실제 Unreal 모듈 구조와 저장소 설정을 기준으로 이 문서를 갱신한다. 코드 예시는 컴파일 가능한 현재 타입과 API만 사용하고, 설계 중인 인터페이스는 그 사실을 표시한다.
